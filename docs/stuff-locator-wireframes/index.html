Stuff Locator — wireframes v2

Locations refactor · structure only, no visual design · Oct 15, 2026 (rev 4) · supersedes v1 (Aug 16), kept alongside as index.v1.html

Still deliberately low-fidelity. Greyscale boxes, orange notes for the reasoning. Screens are tagged NEW CHANGED UNCHANGED. In the location field, a solid chip is a place that already exists; a dashed chip is a new place that's only saved when the item is.

What changed since v1

  • One location picker everywhere an item gets a place (Add, Edit item, Onboarding): pick or create one level at a time, each level becomes a chip, typing continues inside it. Full-path search from v1 stays.
  • No more duplicate places: an exact match (any case) under the same parent replaces the “+ New” row.
  • Browse is navigate + tidy up: a name-only “Add a place here”, and a ⋯ menu on a place's page with Rename, Move into… and Delete (blocked until empty). The separate Add-location form is gone.
  • The way into Browse: the Stuff screen gets two chips under search, All (18) and By place. By place opens Browse, which shows the same header so the chips read as one toggle.
  • Activity is one event log: item added and moved (every move, with where it moved from), place renames, moves and deletes, and item renames, detail edits and deletes. One source, newest first.
  • v1's screen 04 (“By place” grouped list) is replaced by the Browse drill-down the app actually built. Tab bar shows the settled two tabs (Stuff, Activity).
